📦 一行裝起

Paste 落 Terminal 即裝。冇 Homebrew 嘅話 script 會問你要唔要自動裝。

curl -fsSL …/install.sh | bash

Script 會：（必要時裝 Homebrew）→ clone repo → 整 venv → pip install → 開 launch.command → 自動跳去 http://127.0.0.1:8000。可選裝 Calibre（MOBI / AZW3 用）。

Paste 落 PowerShell 即裝。需要 Windows 10 1809+ / Windows 11（內建 winget）。

iwr -useb …/install.ps1 | iex

Script 會：winget install Git + Python 3.11 → clone repo → 整 venv → pip install → 開 launch.bat → 自動跳去 http://127.0.0.1:8000。 可選裝 Calibre（MOBI / AZW3 用）。

係咩

  • 📚 Convert — EPUB ↔ MOBI ↔ AZW3，順便做 zh-CN ↔ zh-TW ↔ zh-HK 變體轉換（OpenCC + 可選 LLM 兜底）。
  • 🔍 Diff — Side-by-side 原文 / 轉換後對照 HTML 報告。
  • 📦 Export Skill — 將本書整成 Claude Skill folder（SKILL.md + JSONL knowledge base），一鍵裝去 ~/.claude/skills/，Claude 之後可以基於書嘅實際內容答你問題。
  • 🧠 Summary — 一鍵 AI 撮要（一句話總結 / 主要人物 / 主題 / 章節摘要 / 每章啟發），用 banana2556 或 Gemini，可以 download PDF。

點解 local-first

  • EPUB 同 API key 永遠留喺你機 — 呢個 landing page 喺 Cloudflare 上面，但所有 processing 都喺你嘅 127.0.0.1，零 traffic 經過 Cloudflare 或者我哋 server。
  • API key 入 localStorage，唔會出去 server 外。你可以喺 ⚙ Settings tab 即時 test 條 key 對 banana2556 啱唔啱。
  • 所有 LLM 結果 cache 落 disk — 中途斷網 / cancel / crash 重 run 嗰陣，已完成嘅 batch 0 token reuse，唔會洗多次錢。
  • 離線都用到（除咗 LLM Summary 一定要 API）。

裝完之後

  1. Finder 入面雙撃 ~/Apps/epubconv/launch.command（或者裝完 script 已經幫你開咗）。
  2. Terminal 自動跑 server，瀏覽器自動開 http://127.0.0.1:8000。
  3. 第一次入 ⚙ Settings tab paste 你嘅 BANANA2556_API_KEY → Save to browser。
  4. 之後用 Convert / Diff / Skill / Summary。Header 個 ↻ Update & Relaunch 掣等於 git pull + 重啟 server。

移除

一行 uninstall（保留 cached LLM 結果）：

curl -fsSL …/uninstall.sh | bash

完全清埋 cache + saved settings 加 -s -- --purge。

Windows 暫時手動 — 喺 PowerShell 跑：

Remove-Item -Recurse "$env:USERPROFILE\Apps\epubconv"

完全清埋 cache 仲要加 Remove-Item -Recurse "$env:USERPROFILE\.config\epubconv"。
